# Character clipart

Add your image files to this folder and commit them with the site. In the
Characters manager, enter the path relative to the site root in a character's
Clipart path field, for example:

```text
characters/my-character.png
```

You can set a clipart path on an existing character or when adding a new one.
Use browser-supported image formats such as PNG, JPG, or WebP. The path is
saved in this browser; the image itself is served from the repository after
the site is deployed.
